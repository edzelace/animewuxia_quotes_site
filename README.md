# Anime Quotes Web App

A simple web app that displays anime quotes. Built with Flask (Python backend) and TailwindCSS (frontend).

## Features

- Search quotes by anime, character, or keyword
- View random anime quotes
- Responsive layout with TailwindCSS

## How to Run Locally

```bash
pip install -r requirements.txt
python anime_quotes_api.py
```

Then open your browser to `http://127.0.0.1:5000`.

## Deploy on Render

1. Push to GitHub
2. Create a new Web Service on [https://render.com](https://render.com)
3. Select Python as environment
4. Set the start command: `python anime_quotes_api.py`
